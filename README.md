# Memestone 0.18.2

Браузерный прототип карточной игры по мотивам Hearthstone со своими мемными картами. React 19, TypeScript и Vite. Свой сервер, аккаунт, база данных и ключи API не нужны. Иллюстрации и шрифты поставляются вместе с приложением; в одиночном режиме внешние сервисы не используются. Комнаты используют внешний WSS-ретранслятор; для сетевой игры нужен интернет.

## Игра на телефоне

После успешной публикации через GitHub Actions игра доступна по адресу:

**https://stisvladnext3-creator.github.io/hearthstonememe/**

Откройте ссылку в Safari или Chrome. Устанавливать Node.js и скачивать исходники не нужно. Ссылку можно добавить на главный экран через меню браузера.

Готовая сборка версии 0.18.2 также лежит в [downloads/memestone-site.zip](downloads/memestone-site.zip). На странице файла в GitHub нажмите **Download raw file**. ZIP можно без распаковки загрузить в Cloudflare Pages.

Публикация настроена в `.github/workflows/deploy.yml`: каждый push в `main` запускает установку по lockfile, тесты, сборку с корректным путём сайта и деплой в GitHub Pages. По просьбе пользователя сетевые исправления с отметкой `[connection-only]` пропускают общие тесты правил; проверка живого подключения выполняется отдельно. Статус публикации находится на вкладке **Actions** репозитория. Для ручного повторного запуска используйте **Deploy Memestone to GitHub Pages → Run workflow**.

## Расположение элементов и отступы 0.18.2

Имя противника находится в левом верхнем углу над его маной. Прогресс его задачи показан слева от портрета вместо прежнего имени и открывает описание по нажатию. Плашка задачи больше не пересекается с колодой. В профиле, разделе «О проекте» и справочнике заданы внутренние отступы от декоративной рамки: текст и кнопки находятся внутри светлого листа, длинные статьи по-прежнему делятся на страницы без прокрутки. Стрелки страниц коллекции центрированы внутри круглых кнопок и выровнены с номером страницы.

## Интерфейс боя 0.18.1

Верхняя навигация удалена полностью. В бою остаётся отдельная шестерёнка справа сверху, а на телефоне рядом доступна кнопка полного экрана. Выход в главное меню, сдача с подтверждением, правила и смена поля находятся в настройках. При выходе локальная партия сохраняется; сетевая продолжается в открытой комнате, что указано в настройках.

История перенесена на левую каменную полосу: кнопка книги и три последних действия открывают журнал слева. На телефоне журнал занимает весь экран. Убраны подписи пустого поля, постоянная подсказка хода, подпись и статус под силой героя. Правила силы и причина недоступности остаются в просмотре и подсказке иконки. На телефоне собственное имя показано слева внизу без подзаголовка.

Счётчики руки и колоды открываются в непрозрачной деревянной плашке с золотой рамкой поверх всей руки, включая увеличенные карты. Колода остаётся доступна для нажатия при полной руке. Красная кнопка «Удалить колоду» перенесена между «Стартовая колода» и «Очистить колоду»; подтверждение сохранено. Число строк колоды на странице рассчитывается по доступной высоте списка.

Проверены только изменённые элементы: расположение и доступность на компьютере, телефоне и в альбомной ориентации, счётчики при полной руке, журнал, выход и возврат в локальный бой, отмена и подтверждение сдачи, удаление колоды. Полный набор правил и внешнее подключение комнат не запускались повторно.

## Читаемый интерфейс, справочник и профиль 0.18.0

В настройках, профиле, справочнике и редакторе используется поставляемый с игрой Inter с кириллицей (SIL OFL): контрастный текст без обводки и декоративных теней. Кнопки и вкладки получили спокойные деревянные и бронзовые поверхности. В мастерской и редакторе убрана общая шапка и подвал; локальная кнопка возврата сохранена, заголовки читаются и на узком телефоне.

Справочник содержит отдельную статью для каждого поддержанного ключевого слова, основы игры, правила колод, комнат и редактора, а также все пять классов с актуальными силами. Есть поиск, разделы, выбор статьи и переходы. Длинный текст делится на страницы по фактическому размеру окна и размеру шрифта, без уменьшения букв и прокрутки. Сведения о проекте обновлены под текущие возможности.

Профиль показывает шесть накопительных показателей: победы, завершённые партии, разыгранные карты, урон героям, урон существам и потраченную ману. Действия учитываются и в незавершённых матчах, а победы и партии — после результата, включая сдачу и ничью. Поддержаны одиночная игра и оба места сетевой партии. Счётчики четырёх действий хранятся в состоянии каждой стороны, а профиль сохраняет только разницу с последним учтённым снимком данного матча. Повторные, запоздалые снимки, перезагрузка и возвращение в комнату не начисляют показатели заново. Старые победы и партии сохраняются; недоступная история урона и розыгрышей не выдумывается — новые поля накапливаются с обновления.

Урон считается по событиям, нанесённым противнику: учитывает броню, ответные удары, хрипы, массовый и избыточный урон. Урон себе и своим существам, усталость, исцеление, уничтожение и превращение не прибавляются. Считается фактическая цена карт после скидок; силы героя тратят ману, но не считаются разыгранными картами. Призыв и получение копии не считаются розыгрышем. Метрики проверяются при загрузке сохранения и сетевого состояния, а при смене мест переходят вместе с игроком. Версия протокола не изменена: новое поле метрик необязательное.

На телефоне кнопка «На весь экран» есть в правом верхнем углу каждого экрана и окна, включая бой, коллекцию, муллиган, мастерскую и редактор. Она использует стандартный Fullscreen API или вариант Safari; при запрете браузера показывает понятное сообщение. Для запуска с главного экрана добавлены метаданные и web manifest без офлайн-кэша, чтобы обновления игры не застревали в service worker.

Проверки обновления ограничены изменёнными механизмами: `npm run test:profile` (14 случаев: атрибуция, ответные удары, хрипы, массовый урон, реальные цены, миграция, повторные снимки, загрузка и смена сетевых мест); браузерные проверки профиля, справочника, настроек, полноэкранного режима, редактора без шапки и настоящего боя с сохранением статистики после двух перезагрузок. Размеры: 1200×720, 390×844, 844×390, 320×568 и 667×375. CI с `[profile-update]` запускает только этот набор, сборку и публикацию. Внешнее соединение комнат повторно не проверяется.

## Классовые рамки, задачи и новые слова 0.16.0

Классовые рамки окрашиваются по принадлежности карты: маг — синий, чернокнижник — фиолетовый, воин — красный, Предвестник бури — тёмно-синий, Позывной «Кот» — тёмно-зелёный. Кристалл редкости, мана, характеристики и бумага описания сохраняют свои цвета. Работает и для новых карт редактора. **Маршал Марс** и **Генерал Михалыч** теперь принадлежат Коту; **Искра хаоса** и **Гениальный план** — магу; **Армия бумажек** — чернокнижнику. Стартовые колоды учитывают класс. В ранее сохранённых колодах перенесённые карты другого класса автоматически заменяются разрешёнными, с сохранением размера и лимитов копий; неизвестные определения остаются восстанавливаемыми черновиками.

**Испепелим их!** — общая легендарная задача за 1 ману, гарантированная в стартовой руке. После розыгрыша считает только гибель **12 вражеских существ**, в том числе призывов, в ход любого игрока. Награда **Т-34**: 7 маны, 8/9, Техника; не может атаковать, в конце своего хода наносит 8 урона одному случайному врагу (герой или существо). В колоду награда не добавляется; при полной руке сгорает. Немота снимает обе способности танка.

**Стегозавр** — общая обычная карта 3 маны, 2/3, Динозавр, провокация. **Тёмный мастер Мяустер** — эпическая карта Кота, 4 маны, 4/5, Мяу, маскировка; при выходе из неё наносит 1 урон всем вражеским существам. Маскировка запрещает вражеский выбор целью, снимается при атаке или нанесении урона; случайные и массовые эффекты могут поражать скрытых существ. Получение урона само по себе не раскрывает существо. Немота снимает маскировку и способность без срабатывания выхода.

**Ящерка** — общая эпическая карта, 8 маны, 6/7, Динозавр, **Громоздкий**. При атаке существа наносит половину текущей атаки его непосредственным соседям с округлением вверх. Только основная цель отвечает на атаку. Соседи фиксируются до гибели цели; маскировка не защищает от бокового урона. При атаке героя и под немотой бокового урона нет. Оба новых ключевых слова доступны в редакторе; там же есть правило выхода из маскировки.

Портрет мага теперь равномерно кадрируется из атласа; широкие значки колод показывают лицо без растяжения. Иллюстрации новых карт подготовлены по присланным референсам. Проверки обновления: `npm run test:card-update` и `npm run test:card-update-ui`, сборка TypeScript/Vite. Общий набор проверок не запускается.

## Предвестник бури, коллекция и импорт 0.14.0

Новый тёмно-синий класс **Предвестник бури** выбирается при создании колоды. Сила **Зов бури** за 2 маны призывает элементаля бури 2/1, один раз за ход. Призыв готовится к атаке до следующего своего хода; полный стол не позволяет потратить силу. Портрет и иконка созданы генератором; активацию сопровождает синий вихрь. Работают бот, сетевые комнаты, немота и временная замена силы.

Коллекция оформлена по присланному макету: восемь карт на большой странице книги, список колод справа, классы сверху, мана и поиск внизу. **Кисточка в верхнем правом углу книги открывает редактор карт.** В 0.15.0 телефон использует ту же полноэкранную страницу книги со списком колод, что и компьютер. Список и состав колоды также перелистываются.

Верхние закладки фильтруют карты каждого класса, все классовые и общие карты. Тип, редкость и «Мои карты» выбираются снизу. По решению пользователя все старые игровые карты остаются общими. При создании новой карты в редакторе задаётся **Класс карты**; общая карта доступна всем колодам, классовая — своему классу. Принадлежность сохраняется в JSON и проверяется при сборке колоды и входе в комнату. Силы героев и новые элементали помечены своими классами, но не добавляются в колоду.

Импорт JSON и внутренний размер набора увеличены до **2000 КБ (2 000 000 байт)**, до 60 карт. Поле класса поддерживает импорт/экспорт. Лимит картинки одной карты остаётся 48 КБ. Сетевой конверт учитывает размер набора и состояния матча; шифрование и фрагментация сохранены. Определения и изображения передаются один раз за соединение с подтверждением готовности, последующие состояния ссылаются на их IDs. Таймер муллигана запускается после передачи набора. При переподключении нужные определения передаются снова.

Проверки обновления: `npm run test:storm` — правила класса, ограничения колод, JSON, протокол и передача определений; `npm run test:storm-ui` — новая коллекция, кисточка, редактор, большой реальный импорт, призыв и вихрь на четырёх размерах телефона; `npm run test:storm-rooms` — два браузера через настоящий внешний WSS, вход по коду / из списка, набор больше 1700 КБ, призыв и возвращение после перезагрузки. CI с `[storm-update]` запускает только относящийся к обновлению набор.

## Редактор карт 0.11.0

Откройте **Коллекция → Редактор карт**. Можно создать карту с нуля, взять любую встроенную карту за основу или нажать **Пример РДШ**, чтобы получить шесть связанных карт: призыв, призывателя, ауру, силу героя, героя со скидкой и задачу.

- Создаются существа, заклинания, герои, силы героев и призывы. Настраиваются название, стоимость, редкость, характеристики, броня, тип, метки, иллюстрация и история карты. Герою можно назначить свою или встроенную силу; новая карта героя сохраняет текущее здоровье.
- Поддерживаются **все механики текущей игры**: провокация, рывок, натиск, эхо, запрет атаки, боевой клич, предсмертный хрип, немота, ауры, начало матча, задачи с наградой, раскопка и «Держать в курсе». Это набор механик Memestone, а не полный каталог всех выпусков Hearthstone.
- Правило состоит из события, условия, цели и действия. Доступны розыгрыш, собственная гибель, призыв/гибель других существ, розыгрыш других карт, начало/конец хода и аура. Цели могут быть выбранными, случайными, массовыми, своим героем, противником, самим существом или участником события.
- Действия: урон, лечение, изменение атаки/здоровья, немота, уничтожение, призыв, добор, добавление/замешивание карты, сброс первых карт руки, удаление карт из колоды, броня, восстановление маны, превращение, удешевляющее превращение, раскопка, замена силы героя и ограничение поля. Настраиваются величина, количество и шанс. Готовые эффекты всех встроенных карт можно сохранить через шаблон или убрать, заменив своими правилами.
- **Синергии** работают по произвольным меткам, типу или конкретной карте. Отдельно задаются фильтр события и фильтр получателя эффекта, сторона, исключение самого источника и условие по столу/руке/колоде либо событиям за матч. Например: аура +2 атаки только РДШ; задача за три своих призыва РДШ; скидка герою за погибшее РДШ на обеих сторонах. Новые карты с меткой РДШ участвуют и в исходной задаче/скидке Джайны.
- Описание составляется из настроек, ключевые слова выделяются. Длинное описание целиком читается во вкладке **Правила** подробного просмотра. Новые карты видны во вкладке **Мои карты** коллекции. Для игры выберите **Изменить колоду**, уберите заменяемую карту, добавьте новую и сохраните 30 карт; лимиты редкости общие для встроенных и своих карт.
- Свои карты работают против бота и в комнатах. Перед боем передаются определения связанного набора и встроенные в него картинки. Хозяин проверяет правила и действия; рука и порядок колоды соперника остаются скрыты. Оба игрока должны обновить страницу: сетевой протокол теперь 4.
- Карты сохраняются в браузере; есть **импорт и экспорт JSON**. Изменение сохраняется отдельной версией: уже начатые матчи используют свои прежние определения и восстанавливаются вместе с ними. Удаление блокируется, если карта нужна колоде или другой карте. Полученные в комнате определения не добавляются в личную библиотеку.

Сначала создайте силу героя или призыв, затем ссылающийся на них эффект. Для синергий задайте одинаковую метку нужным картам; регистр букв не важен. Задача приходит в начало стартовой руки, но начинает считать события после розыгрыша. Снижение стоимости считает события с начала всего матча. Аура прекращается после немоты/гибели источника, а немота героя отключает силу на два его хода.

Редактор использует данные, не исполняемый JavaScript. Проверяются ссылки и типы карт; допустимо до 60 карт/600 КБ в наборе, 12 правил и 8 меток на карту. Картинки уменьшаются при загрузке. Автоматическая цепочка ограничена 200 эффектами на действие, бот завершает слишком длинную комбинацию после 60 действий своего хода. Эти пределы защищают игру от случайных бесконечных правил.

Проверка обновления: отдельные тесты редактора и протокола (`npm run test:editor`), создание карты через интерфейс, колода и настоящий розыгрыш, сохранение, импорт/экспорт, вкладки на телефонах (`npm run test:editor-ui`). `npm run test:custom-rooms` соединяет два браузера через настоящий внешний WSS-сервис с разными наборами своих карт и проверяет героя, силу, заклинание и возвращение в матч. Полный набор старых проверок интерфейса и правил для этого обновления не запускается; CI с отметкой `[editor-checks]` выполняет набор редактора и протокола.

## Исправление подключения 0.10.1

Код создавался через PeerJS, но браузеры не могли установить WebRTC-соединение: стандартные TURN-адреса PeerJS перестали возвращать IP. Зависимый от WebRTC список комнат тоже оставался пустым.

- Рабочий транспорт заменён на MQTT поверх `wss://public.cloud.shiftr.io` через порт 443. Прямое соединение устройств и TURN больше не требуются. Используется документированный публичный сервис shiftr.io для прототипов (`public/public`), без личных ключей.
- Игровые сообщения защищены ECDH P-256 и AES-GCM, при поддержке браузеров сжимаются и делятся на пакеты. Каталог хранит только временные объявления с именем создателя и кодом; свободная комната появляется без соединения с чужим браузером.
- Проверены только подключение по коду, вход из публичного списка, общий старт, передача ходов и возвращение гостя после перезагрузки. Два независимых браузера использовали настоящий внешний WSS-сервис; локальный PeerServer не участвовал. Общий набор тестов правил и интерфейса в этом исправлении не запускался.

После публикации обновите страницу на **обоих** устройствах и создайте новую комнату. Публичный сервис предназначен для тестирования и не гарантирует доступность; для постоянной игры потребуется собственный ретранслятор.

- Новые сгенерированные иллюстрации Джайны-зачинщика и обеих Слизей. Предсмертный урон корректно запускает последующие хрипы; немота их отменяет.
- Деревянное главное меню с круглой панелью и кнопками по присланному примеру, правила, настройки анимаций и звуков, статистика партий.
- Коллекция из 46 карт: 27 пользовательских сущностей, семь призывов, стартовая сила героя «Искра» и 11 базовых карт. «Жанна» 3/5 за 4 маны — явно отмеченная тестовая цель для Максимки, а не реконструкция неприсланной карты.
- Коллекция оформлена как пергаментный альбом: восемь карт на странице на компьютере, четыре на телефоне, вкладки, фильтр маны, поиск и колода в боковой панели. Карты упорядочены по мане. Перелистывание не скрывает карты от поиска.
- Поиск по имени, тексту и типу; категории; фильтр маны; просмотр увеличенной карты. Золотые и серебряные рамки с драконом, отдельные рамки героев и сил героя, овальные портреты, ленты и крупные характеристики.
- Девять заклинаний используют отдельную прямоугольную рамку по присланному образцу: широкая иллюстрация, изогнутая лента названия, кристалл маны слева сверху, самоцвет редкости и светлая панель описания. Одинаковое оформление в коллекции, увеличенном просмотре и руке.
- Вместо 14 прежних заглушек добавлены новые вымышленные иллюстрации. В версии 0.8 отдельно сгенерированы новые рисованные изображения Джайны-волонтера, Джайны-рашера и Забивного Максимки. Дополнительно подготовлены изображения защитника и помощника РДШ. Все изображения включены в сайт и архив; [источник иллюстраций](public/art/generated/README.md).
- Интернет-иллюстрации трёх новых карт включены в сборку. Авторы, источники и лицензии указаны в подробностях карты и [art/web/CREDITS.md](public/art/web/CREDITS.md).
- Раскопка предлагает до трёх разных карт своей колоды и добавляет выбранную копию в руку. Выбор сохраняется после перезагрузки; бот выбирает самостоятельно. Аура Василия действует на текущих и новых существ, снимается после немоты, гибели или превращения и не накапливается при сохранении.
- Редактор колоды на 30 карт с кривой маны и сохранением. В этой небольшой тестовой коллекции разрешены 1 легендарная, 2 эпические, 3 редкие и 3 обычные копии каждой карты.
- Бой против трактирщика Бориса: 30 здоровья, растущая мана, добор, усталость, броня, обмен уроном, провокация, немота, силы героев и все описанные ниже эффекты.
- Бот разыгрывает карты, выбирает цели, совершает выгодные размены и ищет летальный урон. Не разыгрывает заведомо самоубийственную «Хорошая игра.».
- «Тихий час» можно применить к своему или вражескому существу. Например, немота отменяет исчезновение своего Смертокрыла в конце хода или снимает ауру Василия. Немота снимает запрет на атаку Русланчика на обеих сторонах. Сразу атаковать он может, только если уже готов; после призыва требуется следующий свой ход. Выбор союзника корректно отражается в анимации и истории боя.
- «Масик, уничтожитель миров» 7 маны, 6/4: рывок и боевой клич с выбором своего или вражеского существа/героя. Немота героя отключает силу на два его собственных хода. Счётчик уменьшается в конце хода этого героя; повторное применение обновляет его до двух, замена героя снимает немоту.
- «Армия бумажек» за 7 маны заполняет свободные места на обоих столах Бумажками 2/2.
- «Держать в курсе!» за 10 маны оставляет на каждой стороне одно случайное существо, уничтожая остальных. По пять ходов каждого игрока действует лимит в одно существо, включая призывы. Текущий ход считается первым ходом разыгравшего. Обе силы временно становятся добором одной карты за 6 маны. На экране два счётчика; по окончании возвращаются исходные силы (с учётом смены героя) и семь мест. Повторный розыгрыш обновляет оба счётчика до пяти.
- Задача «Сам ты говно» за 1 ману считает восемь своих РДШ, призванных после её розыгрыша. Награда — «Волонтер-босс» в руку; при полной руке сгорает. Если задача есть в колоде, она всегда приходит первой картой стартовой руки у любого участника в одиночном и сетевом бою. Копия берётся из колоды, размер руки сохраняется; для активации задачу нужно разыграть. У задачи есть видимый прогресс, сохраняющийся после перезагрузки.
- «Забивной Максимка» 2 маны, 2/2: наносит 2 урона случайному врагу (включая героя), даёт +1 к атаке выбранному союзнику. На пустом своём столе усиливает себя. Эхо добавляет повторную копию за ту же ману до конца текущего хода. Немота снимает полученный бонус атаки, внешняя аура Василия остаётся.
- «Джайна-рашер» за 4 маны, 5/1: натиск — сразу атакует существ, героя только со следующего своего хода; предсмертный хрип призывает РДШ 1/3 с провокацией. Немота отключает обе способности. «Джайна-волонтер» за 1 ману, 2/1, боевым кличем призывает РДШ 0/2 с провокацией. Обе относятся к типу «Жанна», поэтому Максимка удаляет их из колод.
- Предсмертные хрипы обрабатываются после удаления всех погибших существ и учитывают свободные места. Призванные РДШ продвигают задачу, их гибель снижает стоимость Джайны-ассасина. Натиск работает и у бота; бот не считает его немедленным уроном по герою.
- Название «РДШ» исправлено в картах, типах, эффектах и интерфейсе. Текущий бой и колоды сохранены; текст старых записей истории обновляется при загрузке.
- До 7 существ на поле (одно во время «Держать в курсе»), до 10 карт в руке, сжигание лишнего добора.
- Иллюстрированная история сражения: изображения карты/героя/силы, источник и цель, ход и участник, урон и ответный урон, гибель и превращения. Изображения открывают подробности. Источник и герой записываются снимком в момент действия, поэтому последующая смена героя не меняет старые записи. Хранится до 1000 записей и сохраняется вместе с матчем.
- Анимации полёта существа при атаке, удара по существу или портрету, выкладывания на стол, заклинаний, превращения и силы героя. Результат матча появляется после летального удара. Учитываются настройка «Анимации» и системная настройка уменьшения движения.
- Победа, поражение, сдача, повторная партия. Сдаться можно и во время хода бота.
- Колода, статистика, настройки и незаконченный бой сохраняются в `localStorage`. При выходе в меню бой ставится на паузу. После перезагрузки нажмите «Продолжить бой».
- На картах в руке виден полный текст эффекта. При наведении мыши или фокусе клавиатуры карта увеличивается в 1,65 раза; области нажатия соседей остаются на месте. При выборе цели увеличение убирается, чтобы можно было выбрать союзника. На телефоне сохраняется удержание для подробного просмотра.
- Бой занимает один экран без прокрутки на компьютере, вертикальном и горизонтальном телефоне. Рука из десяти карт перекрывается, каждая карта остаётся доступна для нажатия и удержания. Поле подстраивается под высоту окна и безопасные отступы телефона.
- Сила героя противника видна рядом с его портретом: иллюстрация, название, стоимость, использована ли и немота. Нажатие открывает описание текущей силы, включая временную силу «Держать в курсе».
- Три выбираемых поля: «Фиолетовая цитадель», «Стол в трактире» и новая «Огненная кузница» по присланному референсу с лавой, наковальней и шестернями. Кнопка с картой в бою и раздел в настройках меняют оформление без перезапуска матча. Выбор сохраняется; для цитадели и кузницы подготовлены отдельные вертикальные фоны.
- Адаптивный интерфейс для компьютера и телефона. Удержание карты в руке или существа на любой стороне стола 450 мс открывает описание без розыгрыша/атаки. Движение пальца отменяет удержание и случайный клик. На компьютере также работают правая кнопка мыши и Shift+F10. Escape закрывает окно или отменяет цель.
- Шрифты Russo One и Roboto Condensed поставляются локально. Основной текст увеличен, описания и HUD используют контрастные подложки. Загруженные пользователем исходные карты не перерисовываются. Для карт с присланными фотографиями подготовлены обработанные иллюстрации; происхождение описано в [art/user/README.md](public/art/user/README.md).

## Как играть

1. Нажмите «В бой». Вы ходите первым; задача всегда идёт первой в стартовой руке, если есть в колоде. «Козиныч» тоже гарантированно попадает в неё при наличии в колоде, после задачи.
2. Нажмите на карту в руке. Для направленного заклинания затем выберите подсвеченного врага.
3. Существо атакует со следующего своего хода; рывок позволяет атаковать сразу после выхода, включая героя, с учётом провокации. Выберите готовое существо с зелёным свечением, затем существо или героя противника.
4. При наличии вражеской провокации атаки должны сначала идти в неё. Заклинания и сила героя обходят провокацию.
5. «Искра» за 2 маны наносит 1 урон выбранному персонажу, один раз за ход. Нажмите «Завершить», чтобы передать ход Борису.
6. Удерживайте карту в руке или существо на столе, чтобы прочитать полный эффект и текущие характеристики. В описании отмечено, было ли существо разыграно, призвано или получено превращением.
7. Уменьшите здоровье соперника до нуля. Карты и их тексты можно подробно посмотреть через значок информации в бою или в коллекции.

## Как играть с другом

1. Откройте сайт по HTTPS и выберите **Комнаты** в главном меню.
2. Укажите имя и выберите комнату в списке **Открытые комнаты → Войти**, либо создайте свою.
3. Новые комнаты по умолчанию показываются в списке, пока в них есть свободное место. Отключите «Показывать в списке комнат» для входа только по коду или ссылке. В комнате могут быть два игрока.
4. Создатель нажимает **Начать бой**. Оба используют свои сохранённые колоды; первым ходит случайный игрок.
5. Не закрывайте вкладку создателя: она хранит и ведёт матч. Краткий разрыв не засчитывает поражение, а ждёт восстановления связи. После перезагрузки выберите **Вернуться в комнату** в том же браузере и вкладке.
6. После результата оба подтверждают повторную партию. Явный выход во время боя считается сдачей.

Это первый режим для дружеских партий. Внешний WSS-сервис shiftr.io передаёт зашифрованные игровые сообщения между браузерами. Отдельный игровой сервер и аккаунт для теста не нужны. Создатель является авторитетной стороной матча, поэтому этот режим не предназначен для рейтингового соревнования. Комнаты не продолжают работу после окончательного закрытия вкладки создателя. Статистика профиля пока учитывает партии с ботом.

В версии 0.9 исправлен обрыв на 5–6-м ходу: JSON-канал PeerJS отклонял снимки больше 16 300 байт. В 0.10.1 WSS-транспорт сохраняет разбиение и сборку больших сообщений, семантику JSON и всю историю. Неподтверждённая команда повторяется с тем же ID только при неизменившейся версии состояния, без двойного применения. Старые локальные WebRTC-сценарии остаются для разработки; проверка внешнего транспорта вынесена в `npm run test:connection`.

Список комнат использует временные retained-объявления ретранслятора и heartbeat создателя. Каталог передаёт только имя и код; занятые, закрытые и устаревшие комнаты удаляются. Каталог не зависит от браузера первого посетителя. Закрытие списка не завершает отдельное игровое соединение.

Для разработки без внешнего сервиса сохранён старый локальный транспорт: запустите `npm run rooms:signaling` в отдельном терминале, затем откройте `http://localhost:5173/?localRooms=1`. Локальные сервисы слушают только loopback: 9000 — signaling, 3478 — TURN/TCP. Они нужны только разработке и старым тестам, в GitHub Pages не публикуются. Сайт на GitHub Pages использует WSS; без `localRooms=1` localhost тоже использует настоящий внешний WSS-сервис.

| Василий — хранитель мультивселенных | 3 маны, 4/5, легендарная, тип «Мяу». Провокация. Аура даёт +2 к атаке всем своим существам, включая Василия (на столе 6/5). Несколько аур складываются; немота, гибель или превращение снимают соответствующий бонус. |
| Волонтер-босс | 5 маны, 8/8, тип «Лох». В прототипе эффект срабатывает при розыгрыше и буквально уничтожает ВСЕХ, включая себя; затем призывает двух РДШ 2/4. |

Пушкин, РДШ и силы героя видны в коллекции, но создаются во время боя и не добавляются в колоду. Гибель обоих вариантов РДШ, включая массовое уничтожение и существ под немотой, снижает стоимость Джайны. Удаление карты из колоды и превращение не считаются гибелью.

## Проверка эффектов и «Хорошая игра.»

В `src/game/effects-audit.test.ts` все 26 разыгрываемых карт и все 4 силы героя проверяются за обе стороны. Проверяются призывы, полная рука/стол, броня, усталость, немота, замена героя, превращения и завершение матча. Бот использует тот же `act`, что игрок. Обе стартовые колоды проходят одинаковую проверку состава.

**При розыгрыше «Хорошая игра.» из руки погибает герой владельца**, в том числе Борис, независимо от брони. **Превращение в неё не запускает боевой клич**: например, «Дибильнутый!» может превратить Стража трактира за 5 маны в «Хорошая игра.» за 0 маны. Получается 99/99, но герой остаётся жив. Это правило одинаково для обеих сторон. История помечает такое событие как «Превращение», а удержание существа показывает, что боевой клич не срабатывал.

Доступность силы героя проверяется одной функцией для движка, бота и интерфейса. При полной руке, полном столе, нехватке маны или отсутствии цели удержание силы показывает причину, а не расходует ресурс.

Внешние картинки не меняют правила карты: логика связана с её идентификатором. Применение силы «Искра» теперь записывается как отдельная сила героя, а не как трёхуронное заклинание «Искра хаоса».

## Оригинальные изображения

По запросу пользователя в версии 0.7 вместо всех прежних заглушек добавлены новые вымышленные иллюстрации. Для двух новых Джайн портреты подготовлены инструментом редактирования по присланным картам. Сгенерированные изображения не являются исходными личными фотографиями. Любую иллюстрацию можно заменить своим оригиналом: он сохраняется в браузере без перерисовки.

Откройте карту в коллекции и выберите **Добавить оригинал**:

- **Готовая карта целиком** показывает загруженное изображение вместе с его рамкой, именем, текстом и фотографией без перерисовки.
- **Скриншот редактора с рекламой** скрывает внешние панели редактора по расположению на присланных скриншотах.
- **Только фотография** вставляет оригинальный портрет в рамку приложения.

Поддерживаются JPG, PNG, WebP до 15 МБ. Изображения сохраняются в IndexedDB этого браузера и используются в коллекции, руке, портретах и анимациях. Загрузить, заменить и удалить изображение можно с телефона. Локальная загрузка видна только на этом устройстве.

Чтобы встроить картинки для всех игроков и в скачиваемый сайт, передайте их ZIP-файлом в чат. Исходные файлы нужно сохранить без перерисовки в `public/art/originals/` и зарегистрировать в `src/original-art.ts` с форматом `card`, `editor` или `portrait`. Для соответствия можно использовать имена: `galinka`, `goodgame`, `ruslan`, `casino`, `trachukcha`, `me`, `deathwing`, `maratik`, `oy`, `jaina`, `rds-power`, `fool-power`, `maxim`, `volunteer`. Одинаковый идентификатор используется для карты, портрета и анимаций.

## Структура

- `src/online/room.ts`, `src/online/protocol.ts` — комнаты, авторитетные действия, скрытая информация, переподключение и проекция сторон.
- `src/online/relay.ts`, `src/online/directory.ts`, `src/online/transport.ts` — зашифрованный WSS-транспорт, временный каталог и локальный транспорт разработки.
- `scripts/check-live-connection.mjs` — два браузера через настоящий внешний сервис: вход по коду и из списка, старт, обмен ходами и возвращение гостя.
- `src/components/Online.tsx` — список, создание комнат, приглашения, вход и сетевой бой.
- `e2e/rooms.spec.ts` — 13 сценариев с настоящими браузерными контекстами и WebRTC: полный бой, эхо, большие сообщения, каталог, приватность и переподключение.
- `src/game/cards.ts` — встроенный каталог и стартовые колоды.
- `src/components/CardWorkshop.tsx`, `src/game/custom-schema.ts`, `src/game/custom-cards.ts`, `src/game/custom-engine.ts`, `src/game/custom-presets.ts` — редактор, проверка и хранение наборов, общие эффекты и пример синергии.
- `src/game/engine.ts` — независимый от React движок, проверка действий, эффекты и бот. У действий неизменяемый вход, случайность воспроизводится по seed.
- `src/game/balance-slime.test.ts` — лимиты копий, обновлённая броня, запрет «Хорошей игры.» в превращении и новые предсмертные хрипы за обе стороны.
- `src/game/engine.test.ts`, `src/game/effects-audit.test.ts`, `src/game/charge.test.ts`, `src/game/rush-deathrattle.test.ts` — правила, аудит всех карт за обе стороны и полные симуляции матчей.
- `src/components/Battle.tsx` — игровое поле и выбор целей.
- `src/components/Mulligan.tsx`, `src/game/mulligan.test.ts` — выбор стартовой руки, сохранение отметок, подтверждение и срок.
- `src/components/WindowPages.tsx`, `src/phone.css`, `src/useViewport.ts` — окна и вкладки без прокрутки на телефоне.
- `src/components/DeckPile.tsx` — видимые колоды; события добора обрабатывает `CombatEffects.tsx`.
- `src/components/Collection.tsx` — коллекция и редактор колоды.
- `src/App.tsx` — навигация, главное меню, окна, статистика, цикл бота.
- `src/storage.ts` — сохранение, проверка формата и миграция существующих партий.
- `src/components/BattleHistory.tsx`, `src/game/history.ts` — иллюстрированная история со снимками источников и целей.
- `src/useLongPress.ts` — удержание и отмена случайных действий при прокрутке.
- `src/readability.css` — новые шрифты, альбом и читаемые подложки.

- `e2e/app.spec.ts` — браузерные сценарии меню, коллекции, редактора, боя, сохранения и мобильного интерфейса.

Это первый локальный прототип, а не реализация всех режимов Hearthstone. Автоматический подбор игроков, магазин, наборы, рейтинг, оружие, секреты и прочие будущие механики пока не реализованы. Независимый фан-проект, не связанный с Blizzard Entertainment.

Новые карты добавлены в стартовые колоды игрока и бота. Уже сохранённая пользовательская колода сохраняет свой состав, кроме недоступного теперь «Волонтера-босса»: добавьте их в редакторе или выберите «Стартовая колода». Незавершённая раскопка сохраняется вместе с боем; до выбора другая игровая команда не выполняется.

Портрет Масика подготовлен по присланной фотографии инструментом редактирования изображений и включён в сборку: [описание обработки](public/art/user/README.md). Рывок записывается в состояние существа. Немота на только что вышедшем существе снимает его немедленную атаку; уже потраченная атака не восстанавливается. Счётчик немоты героя сохраняется при перезагрузке. Если Масик немотит своего героя, текущий ход считается первым из двух.
