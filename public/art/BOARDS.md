# Игровые поля

- `battlefield.png` — исходное сгенерированное поле трактира.
- `knights-board.png` — новое сгенерированное оформление по присланному
  референсу: каменные рыцари, фиолетовые ткани, золотой бордюр, песчаник.
- `knights-board-portrait.png` — отдельная композиция того же поля для
  вертикального экрана, подготовленная инструментом редактирования изображений.
- `forge-board.png` — огненная кузница по второму присланному референсу:
  лава, наковальня, шестерни и оружейный стол по углам.
- `forge-board-portrait.png` — вертикальная композиция кузницы, подготовленная
  инструментом редактирования; декорации размещены по углам.

Портреты, карты, история и кнопки добавляются приложением поверх фона.
