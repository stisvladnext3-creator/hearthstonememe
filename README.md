# Memestone 0.2

Браузерный прототип карточной игры по мотивам Hearthstone со своими мемными картами. React 19, TypeScript и Vite. Сервер, аккаунт, база данных и ключи API не нужны. Иллюстрации и шрифты поставляются вместе с приложением; во время игры внешние сервисы не используются.

## Игра на телефоне

После успешной публикации через GitHub Actions игра доступна по адресу:

**https://stisvladnext3-creator.github.io/hearthstonememe/**

Откройте ссылку в Safari или Chrome. Устанавливать Node.js и скачивать исходники не нужно. Ссылку можно добавить на главный экран через меню браузера.

Готовая сборка версии 0.2 также лежит в [downloads/memestone-site.zip](downloads/memestone-site.zip). На странице файла в GitHub нажмите **Download raw file**. ZIP можно без распаковки загрузить в Cloudflare Pages.

Публикация настроена в `.github/workflows/deploy.yml`: каждый push в `main` запускает установку по lockfile, тесты, сборку с корректным путём сайта и деплой в GitHub Pages. Статус публикации находится на вкладке **Actions** репозитория. Для ручного повторного запуска используйте **Deploy Memestone to GitHub Pages → Run workflow**.

## Запуск

Требуется Node.js 20.19+ (в облачной среде проверено на Node.js 24.19.0).

```bash
cd /workspace/hearthstonememe
npm ci
npm run dev
```

Vite слушает порт 5173 на всех интерфейсах. Для локальной разработки вне облака перейдите в папку своего checkout и выполните те же npm-команды.

```bash
npm test           # 34 проверки правил, включая 25 полных партий
npm run build     # TypeScript и production-сборка в dist/
npm run preview   # проверка собранного приложения, порт 4173
npm run test:e2e  # 13 сценариев в настоящем Chromium, после npm run build
```

Браузерные тесты используют `/usr/bin/chromium`, уже установленный в этой облачной среде. На другой машине задайте путь через `CHROMIUM_PATH`. Playwright сам запускает production preview на порту 4173.

## Что уже работает

- Деревянное главное меню с круглой панелью и кнопками по присланному примеру, правила, настройки анимаций и звуков, статистика партий.
- Коллекция из 28 карт: 14 пользовательских сущностей (включая три силы героя), три призыва и 11 базовых карт. «Жанна» 3/5 за 4 маны — явно отмеченная тестовая цель для Максимки, а не реконструкция неприсланной карты.
- Поиск по имени, тексту и типу; категории; фильтр маны; просмотр увеличенной карты. Золотые и серебряные рамки с драконом, отдельные рамки героев и сил героя, овальные портреты, ленты и крупные характеристики.
- Редактор колоды на 30 карт с кривой маны и сохранением. В этой небольшой тестовой коллекции разрешены 1 копия легендарной и до 3 копий остальных карт.
- Бой против трактирщика Бориса: 30 здоровья, растущая мана, добор, усталость, броня, обмен уроном, провокация, немота, силы героев и все описанные ниже эффекты.
- Бот разыгрывает карты, выбирает цели, совершает выгодные размены и ищет летальный урон. Не разыгрывает заведомо самоубийственную «Хорошая игра.».
- До 7 существ на поле, до 10 карт в руке, сжигание лишнего добора.
- История сражения с ходом, участником, источником эффекта, целью, уроном, ответным уроном, гибелью и превращениями. Хранится до 1000 записей и сохраняется вместе с матчем.
- Анимации полёта существа при атаке, удара по существу или портрету, выкладывания на стол, заклинаний, превращения и силы героя. Результат матча появляется после летального удара. Учитываются настройка «Анимации» и системная настройка уменьшения движения.
- Победа, поражение, сдача, повторная партия. Сдаться можно и во время хода бота.
- Колода, статистика, настройки и незаконченный бой сохраняются в `localStorage`. При выходе в меню бой ставится на паузу. После перезагрузки нажмите «Продолжить бой».
- Адаптивный интерфейс для компьютера и телефона, управление кликами/касаниями, закрытие окон и отмена выбора цели через Escape.

## Как играть

1. Нажмите «В бой». Вы ходите первым; «Козиныч» гарантированно попадает в стартовую руку, если присутствует в колоде.
2. Нажмите на карту в руке. Для направленного заклинания затем выберите подсвеченного врага.
3. Существо атакует со следующего своего хода. Выберите готовое существо с зелёным свечением, затем существо или героя противника.
4. При наличии вражеской провокации атаки должны сначала идти в неё. Заклинания и сила героя обходят провокацию.
5. «Искра» за 2 маны наносит 1 урон врагу, один раз за ход. Нажмите «Завершить», чтобы передать ход Борису.
6. Уменьшите здоровье соперника до нуля. Карты и их тексты можно подробно посмотреть через значок информации в бою или в коллекции.

## Присланные карты и тестовые решения

| Карта | Реализованный эффект |
| --- | --- |
| Галинка | 10 маны, 0/1, провокация. Призывает Пушкина 15/15 с провокацией, если на поле есть место. |
| Хорошая игра. | 0 маны, 99/99. Уничтожает собственного героя, игнорируя броню: немедленное поражение. |
| Русланчик | 4 маны, 10/10. Не может атаковать; немота на него не действует. |
| Козиныч | 3 маны. С шансом 50% уничтожает половину оставшейся колоды случайного игрока, с округлением вниз. Гарантированно берётся в начале матча. |
| Трачукча | Карта героя с ценой 0 вместо −1 на изображении. Даёт 99 брони, сохраняет текущее здоровье и заменяет силу героя на «Дибильнутый!». |
| Дибильнутый! | Обновлено по новой присланной карте: за 3 маны превращает всех существ противника в случайных на 5 маны дешевле, не ниже 0. Не вызывает боевые кличи, не считает превращение гибелью и не обновляет право атаковать. При пустом столе противника недоступна. |
| Я | 10 маны, 5/7. Заполняет руку случайными легендарными существами из набора (Галинка, Я, Смертокрыл), до лимита 10. |
| Смертокрыл | 5 маны, 1/1. Уничтожает остальных существ на обеих сторонах, сбрасывает руку владельца и погибает в конце его хода. Немота отменяет это последнее свойство. |
| Маратик | Карта героя за 10 маны. Даёт 5 брони и заменяет силу героя на «Ой». Здоровье сохраняется. |
| Ой | Сила героя за 6 маны: добавляет в руку Смертокрыла 1/1. Используется один раз за ход; при полной руке недоступна. |
| Джайна-ассасин | Базовая стоимость 12, 10 брони. Дешевеет на 1 за каждого погибшего РАШ обоих игроков, до 0. Заменяет силу героя на «Сила РДШ». |
| Сила РДШ | За 4 маны призывает РАШ 2/5. Раз в ход, при наличии места на столе. |
| Максимка-разведчик | 6 маны, 3/5, тип «Максим», эпическая. Удаляет все существа типа «Жанна» из колод обоих игроков, сохраняя руки и стол. |
| Волонтер-босс | 5 маны, 8/8, тип «Лох». В прототипе эффект срабатывает при розыгрыше и буквально уничтожает ВСЕХ, включая себя; затем призывает двух РАШ 2/4. |

Пушкин, РАШ и силы героя видны в коллекции, но создаются во время боя и не добавляются в колоду. Гибель обоих вариантов РАШ, включая массовое уничтожение и существ под немотой, снижает стоимость Джайны. Удаление карты из колоды и превращение не считаются гибелью.

## Оригинальные изображения

Оригинальные вложения чата не появились в файловой системе этой среды. Личные фотографии не заменяются сгенерированными лицами: пока оригинал отсутствует, в соответствующем месте показана отметка «Твой оригинал».

Откройте карту в коллекции и выберите **Добавить оригинал**:

- **Готовая карта целиком** показывает загруженное изображение вместе с его рамкой, именем, текстом и фотографией без перерисовки.
- **Скриншот редактора с рекламой** скрывает внешние панели редактора по расположению на присланных скриншотах.
- **Только фотография** вставляет оригинальный портрет в рамку приложения.

Поддерживаются JPG, PNG, WebP до 15 МБ. Изображения сохраняются в IndexedDB этого браузера и используются в коллекции, руке, портретах и анимациях. Загрузить, заменить и удалить изображение можно с телефона. Локальная загрузка видна только на этом устройстве.

Чтобы встроить картинки для всех игроков и в скачиваемый сайт, передайте их ZIP-файлом в чат. Исходные файлы нужно сохранить без перерисовки в `public/art/originals/` и зарегистрировать в `src/original-art.ts` с форматом `card`, `editor` или `portrait`. Для соответствия можно использовать имена: `galinka`, `goodgame`, `ruslan`, `casino`, `trachukcha`, `me`, `deathwing`, `maratik`, `oy`, `jaina`, `rds-power`, `fool-power`, `maxim`, `volunteer`. Одинаковый идентификатор используется для карты, портрета и анимаций.

## Структура

- `src/game/cards.ts` — каталог и стартовые колоды. Новые карты добавляются здесь.
- `src/game/engine.ts` — независимый от React движок, проверка действий, эффекты и бот. У действий неизменяемый вход, случайность воспроизводится по seed.
- `src/game/engine.test.ts` — правила и полные симуляции матчей.
- `src/components/Battle.tsx` — игровое поле и выбор целей.
- `src/components/Collection.tsx` — коллекция и редактор колоды.
- `src/App.tsx` — навигация, главное меню, окна, статистика, цикл бота.
- `src/storage.ts` — сохранение, проверка формата и миграция существующих партий.
- `src/components/CombatEffects.tsx` — анимации по событиям движка, с привязкой к реальным координатам существ и героев.
- `src/components/WoodMenu.tsx`, `src/classic.css` — главное меню и классические рамки.
- `src/artwork.tsx`, `src/components/ArtworkUpload.tsx` — загрузка оригиналов и хранение в браузере.
- `public/art/` — фон деревянного меню, рамки, стол, фон трактира и атлас базовых персонажей. Шрифты находятся в npm-зависимостях, загружаются локально.
- `e2e/app.spec.ts` — браузерные сценарии меню, коллекции, редактора, боя, сохранения и мобильного интерфейса.

Это первый локальный прототип, а не реализация всех режимов Hearthstone. Сетевая игра, подбор игроков, магазин, наборы, рейтинг, оружие, секреты, предсмертные хрипы и прочие будущие механики пока не реализованы. Независимый фан-проект, не связанный с Blizzard Entertainment.
