# Портрет Масика

`masik-portrait.png` подготовлен по присланной пользователем фотографии котёнка
с помощью инструмента редактирования изображений: портрет приближен и подогнан
под овальное окно карты. Это обработанный портрет, не исходный JPG из камеры.

Встроенное изображение используется для карты, существа на столе и истории боя.
При желании его можно заменить собственным исходным фото в окне карты.

## Новые карты

`new-cards-atlas.png` — четыре иллюстрации, подготовленные инструментом
редактирования изображений по окнам фотографий на присланных картах:
бумажки, Боб Росс, жест рукой и Забивной Максимка. Рамки и надписи убраны,
кадры приближены и очищены. Это обработанные изображения по референсам,
а не исходные файлы фотографий. Квадранты выбираются стилями при отображении.

`jaina-portraits.png` подготовлен инструментом редактирования по двум новым
присланным картам. Слева — портрет Джайны-рашера, справа — Джайны-волонтера.
Рамки убраны, лица приближены; это обработка референсов, не исходные фото.
