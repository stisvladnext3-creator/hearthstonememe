# Новые иллюстрации

Эти изображения созданы генератором по явному запросу пользователя для карт,
у которых не было иллюстраций. Это вымышленные персонажи и сцены,
а не оригинальные личные фотографии из ранних референсов.

Оба атласа содержат по восемь квадратных сцен: четыре столбца, две строки.

- `characters-a.png`, сверху: Галинка, Хорошая игра, Русланчик, Козиныч;
  снизу: Трачукча, Я, Смертокрыл, Маратик.
- `characters-b.png`, сверху: Джайна-ассасин, Сила РДШ, Дибильнутый,
  Максимка-разведчик; снизу: Волонтер-босс, Ой, РДШ-защитник, РДШ-помощник.

Координаты сцен указаны в `src/original-art.ts`. Игрок может заменить
иллюстрацию собственным файлом в подробностях карты.

`jaina-maxim.png` — три новые иллюстрации, созданные по отдельному запросу
в версии 0.8. Слева направо: Джайна-волонтер с защитником, Джайна-рашер
с розовыми следами скорости, Забивной Максимка с магическими копиями.
Это вымышленные рисованные персонажи; прежние обработанные портреты
заменены этими иллюстрациями в общем каталоге.

## Джайна-зачинщик и Слизь

`jaina-slimes.png` — новый сгенерированный атлас из трёх иллюстраций: Джайна-зачинщик, Слизь 1/4 и её призыв 0/2. Создан по текстовому описанию для этой игры; это вымышленные персонажи, а не личные фотографии. Используется в коллекции, руке, портретах и истории боя.

## Рамки легендарных карт

`../premium-frames.png` — прозрачный атлас двух рамок (1505 × 1045): слева тёмная рамка с большой иллюстрацией, справа алмазная. Сгенерирован по двум присланным пользователем пустым рамкам для версии 0.9.2. Каждая половина атласа используется без изменения исходного PNG; координаты иллюстрации, названия, типа и единственного родного самоцвета находятся в `src/components/CardFrame.tsx` и `src/card-layout.css`.
