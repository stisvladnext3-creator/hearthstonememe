# Готовая сборка Memestone 0.9.3

`memestone-site.zip` — готовый статический сайт для загрузки в Cloudflare Pages или другой статический хостинг. В архиве на верхнем уровне находятся `index.html`, `assets/`, `art/` и иконка. Node.js на телефоне не нужен.

Это сборка тестовой версии 0.9.3. Актуальная версия сайта автоматически собирается из `main` и публикуется через GitHub Actions в GitHub Pages.

Скачать ZIP: откройте файл в GitHub и нажмите **Download raw file**. Исходный код проекта расположен в корне репозитория.

В версии 0.9.3 закреплены типы существ на нижней плашке, выделены ключевые слова способностей и добавлены два сохраняемых оформления легендарных карт. Выбор доступен в подробном просмотре карты.

Задачи из колоды всегда приходят первыми в стартовую руку обоих участников, включая сетевые комнаты. Размер руки и число копий в колоде сохраняются.
